# 100 Days of Code Journal

A printable and digital journaling system designed to help developers track their progress throughout the 100 Days of Code challenge. This project includes both a Daily Log and a Weekly Check-In template, providing a structured way to document learning, coding sessions, accomplishments, challenges, and goals.

---

## Overview

The 100 Days of Code Journal was created to encourage consistent coding habits, self-reflection, and progress tracking throughout a coding journey.

The project contains two primary components:

* **Daily Log Template** — Record daily coding activities, lessons learned, wins, and challenges.
* **Weekly Check-In Template** — Reflect on weekly accomplishments, obstacles, habits, and goals for continued growth.

The clean dark-theme design is inspired by modern developer tools and coding environments.

## Installation

```bash

```


